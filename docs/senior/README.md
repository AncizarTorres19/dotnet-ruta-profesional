## Criterio de dominio

No existe una lista de APIs que certifique Senior. Se demuestra con decisiones justificables, producción operable, aprendizaje de incidentes y capacidad de ayudar al equipo a entregar mejor.

## Proyecto sugerido: plataforma operable de pedidos

Extiende la API Mid con despliegues reproducibles, control de acceso, trazas, métricas, logs, límites de saturación, migraciones seguras, política de dependencias, health/readiness checks y procedimiento de restauración probado. Define objetivos de latencia y disponibilidad y valida con pruebas de carga.
