## Criterio para avanzar

Implementa una aplicación de consola que reciba entradas, modele conceptos de negocio, valide casos inválidos, guarde y recupere datos con JSON y tenga pruebas para las reglas principales.

## Proyecto sugerido: administrador de gastos

Permite registrar, listar, filtrar y resumir gastos. Comienza en memoria; agrega persistencia en un archivo JSON y pruebas. Usa `decimal` para importes. Espera antes de agregar una base de datos o interfaz web: aprende primero las reglas y tipos.
